## Сервер приложений

**Таблица 1.3.1 – Требования к серверу приложений**

| Ресурс | Требования | Примечания |
|---|---|---|
| Операционная система | Операционные системы семейства Linux 64-bit (рекомендуется) такие как:<br>Ubuntu, Debian, CentOS, RedHat, Astra |   |
| CPU | Минимальное число ядер: 8<br>Рекомендуемое число ядер: 16 |   |
| Disk | Минимальное дисковое пространство: 120ГБ | Дисковое пространство необходимо для размещения специального программного обеспечения, пользовательских файлов, загружаемых средствами CPM. |
| RAM | Минимальный объём оперативной памяти: 10ГБ Рекомендуемый объём оперативной памяти: 16ГБ |   |

## Сервер базы данных

В качестве базы данных используется сервер PostgreSQL версии 14 и выше. Рекомендуется уточнять приоритетную версию PostgreSQL перед развертыванием системы. В качестве сервера базы данных может использоваться существующий сервер СУБД Postgres с развертыванием на нем схемы данных Larix.Tender, Larix.Contract.

## Рабочие станции

- Платформа – Windows, Linux c установленным браузером.
- Тип процессора - не ниже Intel Core i5.
- Оперативная память - не менее 8 GB RAM.
