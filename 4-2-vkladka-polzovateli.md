# 4.2. Вкладка «Пользователи»

При переходе на вкладку «Пользователи» (1) отображаются все пользователи, зарегистрированные в Пространстве (2).

Для отображения списка пользователей, связанных с конкретным проектом, требуется выбрать нужный Проект через поле выбора проектов (3).

![Рисунок 4.2.1 – Вкладка «Пользователи»](/larix-nexus/assets/img-016.png)

*Рисунок 4.2.1 – Вкладка «Пользователи»*

## 4.2.1 Добавление пользователей

Для добавления пользователя в Проект необходимо удостовериться, что в поле выбора проекта (1) установлено название соответствующего Проекта. После этого нажать на кнопку «Добавить пользователя» (2).

![Рисунок 4.2.1.1 – Добавление пользователя в Проект](/larix-nexus/assets/img-017.png)

*Рисунок 4.2.1.1 – Добавление пользователя в Проект*

В Проект можно добавить пользователя, который уже зарегистрирован в пространстве:

![Рисунок 4.2.1.2 – Выбор пользователя](/larix-nexus/assets/img-018.png)

*Рисунок 4.2.1.2 – Выбор пользователя*

В открывшемся окне выбрать пользователя, которого необходимо добавить к проекту.

## 4.2.2 Редактирование данных и удаление профиля пользователя

Для действий с пользователем в рамках всего Пространства в поле выбора проектов (1) установить значение «Все проекты».

Для действий с пользователем в рамках конкретного Проекта в поле выбора проектов (1) установить значение, соответствующее названию нужного Проекта.

Сведения о пользователе можно удалить (2) или отредактировать (3).

![Рисунок 4.2.2.1 – Действия с пользователями](/larix-nexus/assets/img-019.png)

*Рисунок 4.2.2.1 – Действия с пользователями*

При нажатии на кнопку «Редактировать» появится окно, где можно внести соответствующие изменения в профиль пользователя:

![Рисунок 4.2.2.2 – Редактирование профиля пользователя](/larix-nexus/assets/img-020.png)

*Рисунок 4.2.2.2 – Редактирование профиля пользователя*

**Таблица 4.2.2.1 – Редактирование профиля пользователя**

| № | Наименование | Функционал |
|---|---|---|
| 1 | Список проектов | Список проектов, доступных пользователю |
| 2 | Роль | Назначение роли в проекте |
| 3 | Администратор проекта | Включение и выключение возможности администрирования проекта |
| 4 | Сохранить изменения | Сохранение внесенных изменений |
