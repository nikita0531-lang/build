Проект — верхний уровень: стройка, здание, комплекс. Внутри проекта строится дерево
объектов: корпуса, секции, этажи, квартиры, помещения. К объектам привязываются
замечания, инспекции и работы, поэтому дерево лучше завести до начала работы.

---

## 3.1. Реестр проектов

**Меню → Проекты**

![Реестр проектов](/user-guide/images/04-projects-registry.png)

Каждый проект — плитка со статусом, изображением, описанием и счётчиками объектов
и замечаний по статусам. Внизу плитки: «глаз» — просмотр, «⋮» — меню, **«Перейти»** —
открыть проект.

### Создание проекта

**«Добавить»** → форма:

| Поле | Описание |
|---|---|
| **Название проекта** * | До 100 символов |
| **Описание проекта** | До 250 символов |
| **Изображение проекта** | Картинка на плитке; выбирается из библиотеки изображений |
| **Требовать тип замечания при создании** | Если включено, замечание нельзя создать без указания типа |
| **Локальные типы замечаний** | Типы, действующие только в этом проекте, помимо общих |

Сохранение — **«Создать»**. Появится сообщение «Проект сохранён».

### Прочие операции

- **Импорт** — массовая загрузка проектов из Excel (шаблон
  «Проекты_шаблон_импорт.xlsx»).
- **Удаление** — через «⋮», с подтверждением «Удалить проект «...»?».
- **Смена статуса** — через «⋮»: «Новый» → «В работе» → «Закрыто».
  Закрытый проект можно вернуть в работу.

## 3.2. Карточка проекта

Открывается по **«Перейти»**. Сверху — вкладки:
**Обзор проекта · Замечания · Работы · Объекты · Шахматка**.

![Обзор проекта](/user-guide/images/05-project-overview.png)

### Обзор проекта

- **Плитки статистики**: Всего замечаний, Новых, В работе, Выполнено, На проверке,
  На доработку, Закрыто.
- **График «Замечания»** — распределение по статусам.
- **«Последние замечания»** — свежие записи со статусом, описанием и объектом;
  клик открывает карточку.
- **Вложения** — файлы уровня проекта.

## 3.3. Объекты проекта

**Карточка проекта → вкладка «Объекты»**

![Объекты проекта](/user-guide/images/06-project-objects.png)

Реестр показывает дерево: **Название объекта, Статус, Проект, Описание**.

### Создание объекта

**«Добавить»**:

| Поле | Описание |
|---|---|
| **Проект** * | Подставляется из контекста |
| **Родительский объект** | Пусто — объект верхнего уровня; иначе выберите узел дерева |
| **Название объекта** * | Например «Корпус 2», «Этаж 8», «Квартира 281» |
| **Описание** | Произвольный комментарий |
| **Статус** | «Новый» при создании |

Порядок один: сначала корпуса, потом секции внутри корпусов, потом этажи, потом
помещения. Глубина вложенности не ограничена.

### Импорт дерева

**«Импорт»** принимает Excel с колонками пути и уровня («Объекты_шаблон_импорт.xlsx»),
поэтому дерево целиком заводится одним файлом. Выгрузка **XLSX** делает плоский обход
дерева с путём и уровнем — файл можно поправить и залить обратно.

### Статусы объекта

«Новый» → «В работе» → «Закрыто»; закрытый возвращается в работу.

При закрытии система спросит: **«Закрыть также все дочерние объекты?»**.

Закрыть объект нельзя, пока:

- не все дочерние объекты в том же статусе;
- не все замечания объекта закрыты;
- не все работы по объекту завершены — каждая должна быть принята или отменена.

Система выдаст точную причину отказа.

> Закрытый объект «замораживается»: работы и записи о выполнении в нём больше
> не меняются.

## 3.5. План объекта, зоны и метки

**Карточка объекта → вкладка «План»**

![Вкладка «План» без плана](/user-guide/images/07b-object-plan-empty.png)

Пока план не загружен: «План пока не загружен. Загрузите файл, чтобы начать».

### Загрузка плана

- **«Выбрать»** — взять изображение из библиотеки.
- **«Загрузить и обрезать»** — выбрать файл и обрезать до загрузки в хранилище.
- **«Обрезать»** — обрезать уже загруженный план; создаётся новый обрезанный план.
- **«Сменить план»**, **«Удалить план»** — замена и удаление.

Поддерживаются изображения и PDF. У PDF в панели появляется переключатель **«Стр.»**.

Инструмент обрезки: **«Прямоугольник»** — зажать и растянуть рамку;
**«Произвольная зона»** — обвести область, удерживая кнопку мыши; **«Сбросить»**
отменяет выделение, **«Обрезать»** применяет.

### Панель просмотра плана

| Переключатель | Что показывает |
|---|---|
| **Показать дочерние** | Контуры вложенных объектов |
| **Показать зоны** | Разметку зон |
| **Показать метки** | Метки на плане |
| **Показать замечания** | Точки замечаний |

### Зоны

Зона — контур на плане, закреплённый за объектом (например, контур квартиры на
плане этажа).

1. Нажмите **«Зона»**.
2. Обведите контур — минимум 3 точки.
3. В форме **«Сохранить зону»** укажите **Родительский объект** * и
   **Наименование зоны** *.

Зону нельзя создать или вынести за пределы зоны текущего объекта — система сообщит
«Нельзя создать зону вне зоны текущего объекта».

Редактирование и удаление — кнопка **«Редактировать зону»**.

### Метки

Метка — точка на плане с названием, комментарием и привязанными замечаниями.

1. Нажмите **«Маркер»**.
2. Поставьте точку (вне зоны текущего объекта поставить нельзя).
3. Заполните **Название метки** *, **Комментарий**, **Замечания** *.

Можно расставить несколько меток подряд: на вопрос **«Добавить ещё метки?»**
ответьте «Да», расставьте нужное количество и подтвердите — метки сохранятся пачкой.

> Права на разметку выдаются отдельно: **«Разметка на плане»** и **«Маркеры на плане»**.

## 3.6. Шахматка

**Карточка проекта → вкладка «Шахматка»**

![Шахматка](/user-guide/images/08-project-chessboard.png)

Шахматка — сводка замечаний по дереву объектов в виде матрицы.

- **«Строки =»** и **«Столбцы =»** задают уровни дерева, которые сопоставляются.
  По умолчанию уровни называются «Корпус», «Этаж», «Квартира», «Комната» — реальные
  подписи берутся из вашего дерева.
- В каждой ячейке — кольцевая диаграмма и число замечаний; цвета соответствуют статусам.
- Клик по ячейке проваливается на уровень ниже, **«На уровень выше»** возвращает.
- **«Поменять местами уровни»** меняет строки и столбцы местами.
- **«Перейти»** открывает карточку объекта.

Шахматка отвечает на вопрос «где горит»: видно, в каком корпусе и на каком этаже
скопились незакрытые замечания.
