> Лицензируемый модуль «Учёт выполненных работ». Без него разделы «Договоры»
> и «Работы» доступны только на чтение.

Модуль отвечает на вопрос «сколько сделано и сколько принято». Схема такая:

```
Договор ──► Работа (план: объём, цена, сроки) ──► Записи журнала (факт по дням)
                                                        │
                                                        ▼
                                              Инспекция (приёмка объёма)
                                                        │
                                                        ▼
                                              Подписано ──► выгрузка КС-2
```

---

## 7.1. Договоры

**Меню → Договоры**

![Реестр договоров](/user-guide/images/20-contracts.png)

### Создание договора

**«Добавить»**:

**Основное:** **Номер** *, **Наименование** *.

**Стороны и сроки:** **Контрагент** *, **Дата договора** *, **Дата начала** *,
**Дата окончания** *. Дата окончания не может быть раньше даты начала.

**Проект и объект:** **Проект** *, **Объект**.

![Форма создания договора](/user-guide/images/37-contract-create-form.png)

### Карточка договора

![Карточка договора](/user-guide/images/21-contract-card.png)

Реквизиты договора: номер, наименование, контрагент, проект, объект, дата договора
и сроки. Ниже — работы по договору.

Импорт договоров из Excel **всегда создаёт новые записи** — повторная загрузка того
же файла добавит дубликаты.

## 7.2. Работы

**Меню → Работы**

![Реестр работ](/user-guide/images/22-works.png)

Реестр показывает: Наименование работы, Договор, Проект, Объект, Вид работ,
Объём по договору, Выполнено, Принято, Выполнение (%), Ед. измерения, Цена за ед.,
Плановая стоимость, Ответственный, Сроки, Статус.

Стрелка «›» раскрывает подработы.

### Создание работы

**«Добавить»**

![Форма создания работы](/user-guide/images/29-work-create-form.png)

**Договор и объект**

| Поле | Описание |
|---|---|
| **Договор** | Можно не указывать — тогда работы считаются выполненными своими силами |
| **Проект** * | Проект |
| **Объект** * | Объект дерева |

**Работа**

| Поле | Описание |
|---|---|
| **Тип работы** * | «Самодостаточная» или «Комплексная» |
| **Наименование работы** * | Название позиции |
| **Вид работ** | Из справочника видов работ |

**Объём и стоимость**

| Поле | Описание |
|---|---|
| **Объём по договору** * | Плановый объём, больше нуля |
| **Ед. измерения** * | Из справочника единиц |
| **Цена за ед.** | Цена единицы |
| **Плановая стоимость** | Считается автоматически: объём × цена |

**Сроки и ответственный:** **Ответственный** *, **Дата начала** *, **Дата окончания** *.

**Дополнительно:** **Место работ (этаж, оси)**, **Ссылка на РД**,
**Объём по ПД**, **Объём по РД**.

> **Сроки вне договора.** Если даты работы выходят за сроки договора, система
> потребует **«Обоснование сроков вне договора»**. Без обоснования сохранить нельзя.

### Самодостаточная и комплексная работа

| Тип | Как ведётся |
|---|---|
| **Самодостаточная** | Факт вносится прямо в неё |
| **Комплексная** | Факт вносится **только в подработы**; объём, процент и статус родителя считаются по ним |

Подработа наследует договор, проект и объект от родителя; цена задаётся только на
верхнем уровне. Одна из подработ может быть помечена **главной** — через меню строки
**«Назначить главной»**; главная должна иметь ту же единицу измерения, что и родитель.

Тип работы можно менять, **пока у неё нет ни подработ, ни записей о выполнении**.

## 7.3. Карточка работы и журнал выполнения

![Карточка работы](/user-guide/images/23-work-card.png)

**Шапка:** Договор, Проект, Объект, Статус, Тип работы, Вид работ, Ответственный,
Сроки, Плановая стоимость, Место работ.

**Строка объёмов:** Объём по договору · Выполнено · Принято · Остаток и полоса
выполнения в процентах.

> **Принято** — объём, прошедший приёмку: записи журнала в статусах «Принят»
> и «Подписано».

**Вкладки:** **Внесённые записи · Табель · Вложения · Чат · Активность**.

### Внесение факта

Кнопка **«Внести выполнение»**:

| Поле | Описание |
|---|---|
| **Дата выполнения** * | День, за который вносится объём |
| **Фактический объём** * | Больше нуля; показывается «Остаток» |
| **Комментарий** | Пояснение |

Ограничения:

- Факт вносится, пока работа в статусе «План», «В работе» или «Выполнена».
  Приостановленная, принятая и отменённая закрыты для внесения.
- У комплексной работы факт вносится в подработы.
- Если объект закрыт — «Объект закрыт: работы и записи о выполнении в нём
  больше не меняются».
- При превышении плана система предупредит «Выполнено больше запланированного».

Флажок **«Показывать подработы»** в журнале показывает записи подработ, из которых
складывается объём родителя.

Удаление записи журнала уменьшает выполненный объём — система предупредит об этом.

### Отправка объёма на приёмку

Кнопка **«Запросить инспекцию»**:

1. Отметьте записи журнала, которые отдаёте на приёмку.
2. Подтвердите.

Нельзя отдать записи, которые уже приняты, подписаны, отменены или уже ждут свою
инспекцию — система перечислит причину.

Дальше вердикт инспекции автоматически переводит объём в «Принят» или «Отклонён»
(см. [Инспекции](/user-guide/06-inspections)).

## 7.4. Табель

**Меню → Работы → вкладка «Табель»**

![Табель](/user-guide/images/24-works-timesheet.png)

Табель — сетка «работы × дни» за две недели: сколько объёма внесено в каждый день.

- **«Предыдущие две недели»**, **«Следующие две недели»**, **«Сегодня»** — навигация.
- **Поиск по наименованию работы** — фильтр строк.
- Клик по ячейке открывает **«Записи за <дата>»**.

Пометки в ячейках:

- «Запись отдана на приёмку — правится только до неё»;
- «Записей за день: 3. Правка — в журнале работы».

Табель удобен прорабу: видно, что вносилось по дням, и сразу правится.

## 7.5. Статусы

### Статусы работы

```
План ──────► В работе ──────► Выполнена ──────► Принята
  │             │                  │                │
  ├─► Приостановлена ◄─────────────┘                │
  │             │                                   │
  └─────────────┴──────────► Отменена ◄─────────────┘
```

| Статус | Как ставится |
|---|---|
| **План** | При создании |
| **В работе** | **Автоматически** при внесении первого факта |
| **Выполнена** | **Автоматически**, когда факт добирает плановый объём |
| **Принята** | **Автоматически**, когда все записи журнала приняты |
| **Приостановлена** | Вручную из «План» или «В работе» |
| **Отменена** | Вручную из любого рабочего статуса; конечный |

Возобновление из «Приостановлена» в «В работе» доступно ответственному.
При переводе в «Приостановлена» система потребует **причину**: «Без причины статус
не сменить» — например «приостановлено до поставки материалов».

### Статусы записи журнала

```
В работе ──► Готов к приёмке ──► Принят ──► Подписано
    ▲               │
    └── Отклонён ◄──┘
```

| Статус | Смысл |
|---|---|
| **В работе** | Факт внесён, на приёмку не отдан |
| **Готов к приёмке** | Отдан на проверку |
| **Принят** | Инспекция приняла объём |
| **Отклонён** | Инспекция не приняла; после переделки возвращается в «В работе» |
| **Подписано** | Объём подписан и попадает в КС-2; конечный |
| **Отменён** | Конечный |

Переход **«Принят» → «Подписано»** делает человек — для него нужно право
«Журнал выполнения: изменение статуса».

> Ручной путь «В работе → Готов к приёмке» существует для заказчиков без модуля
> инспекций: иначе объём никогда не дошёл бы до приёмки.

## 7.6. Выгрузка КС-2

**Меню → Работы → кнопка «Выгрузка КС-2»** в панели инструментов реестра.

Выгружается файл `ks2.xlsx` с накопительным итогом по объёмам. Выгрузка учитывает
текущий контекст экрана: открытый внутри проекта реестр выгружает только работы
этого проекта.

Это финансовый документ, поэтому кнопка закрыта отдельным правом
**«Договоры: выгрузка КС-2»** — у роли может быть полный доступ к работам
и при этом не быть права на КС-2.

## 7.7. Аналитика работ

**Меню → Аналитика → вкладка «Работы»** (старая ссылка «Аналитика работ»
перенаправляет сюда же).

- Фильтры **«Договор»** и **«Проект»**.
- Показатели: **План**, **Факт**, **Выполнение**, **Прогноз завершения**.
- **«Накопительный итог (S-кривая)»** — план против факта во времени.
- **«Освоение по видам работ»** — где идёт с опережением, а где отстаёт.

Если данных мало, прогноз не строится: «Недостаточно данных».

## 7.8. Права модуля

| Сущность | Права |
|---|---|
| **Договоры** | Просмотр, Создание, Редактирование, Удаление, **Выгрузка КС-2** |
| **Работы** | Просмотр, Просмотр всех, Создание, Редактирование, Удаление, Изменение статуса |
| **Журнал выполнения** | Просмотр, Создание, Редактирование, Удаление, Изменение статуса |

> Журнал вынесен в отдельную сущность намеренно: производитель работ вносит факт,
> но не должен править плановые объёмы и цены.
