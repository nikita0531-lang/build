Справочники — общий словарь системы. Они задают, какими категориями и типами
описываются замечания, какие есть подрядчики, виды работ и единицы измерения.
Чем аккуратнее заведены справочники, тем осмысленнее аналитика.

Большинство справочников поддерживают **Импорт** из Excel и **XLSX**-выгрузку;
формат выгрузки совпадает с форматом импорта.

---

## 9.1. Справочники замечаний

**Меню → Справочники → Справочники замечаний**

![Справочники замечаний](/user-guide/images/30-issue-dictionaries.png)

Экран разделён на две части: слева **«Категории»**, справа **«Типы замечаний»**.

### Категории

Крупные разделы: «Земляные работы и земляные сооружения», «Каменная кладка»,
«Лифтовое оборудование», «Отделочные работы», «ОТиПБ» и т. д.

Кнопка **«+»** над списком создаёт категорию:

| Поле | Описание |
|---|---|
| **Название категории** * | Например «Кровельные и теплоизоляционные работы» |
| **Описание** | Комментарий |

Клик по категории фильтрует правую таблицу — подпись меняется на
«Показаны типы категории: ...». Крестик сбрасывает фильтр
(«Показать типы всех категорий»).

### Типы замечаний

Тип — конкретная формулировка нарушения внутри категории, например
«Отклонения свай в плане или от вертикали».

**«Добавить»**:

| Поле | Описание |
|---|---|
| **Категория** * | К какой категории относится |
| **Родительский тип** | Типы можно вкладывать друг в друга — получается дерево |
| **Название типа замечания** * | Формулировка |
| **Описание** | Пояснение |
| **Ориентировочное время** | Нормативный срок устранения: дни, часы, минуты |

> **Ориентировочное время — важное поле.** По нему система автоматически считает
> «Планируемую дату устранения» при создании замечания. Заполните его для типовых
> нарушений — и сроки перестанут назначаться на глаз.

Выгрузка типов делает плоский обход всего дерева с путём и уровнем.

## 9.2. Контрагенты

**Меню → Справочники → Контрагенты**

![Контрагенты](/user-guide/images/31-contragents.png)

Юридические лица: подрядчики, заказчики, поставщики. Контрагент указывается
в замечании, инспекции и договоре.

**«Добавить»** — форма из четырёх секций:

| Секция | Поля |
|---|---|
| **Основное** | **Наименование** * |
| **Реквизиты** | ИНН, КПП, ОГРН / ОГРНИП |
| **Адреса** | Юридический адрес, Фактический адрес |
| **Контакты** | Телефон |

> Контрагент связан с пользователями: в карточке пользователя указывается,
> какую организацию он представляет. На этом строится разграничение — представитель
> подрядчика видит свой контур работы.

## 9.3. Виды работ

**Меню → Справочники → Виды работ**

![Виды работ](/user-guide/images/32-work-types.png)

Общий справочник для инспекций и учёта работ: «Сантехнические работы»,
«Фасадные работы», «Кровельные работы», «Благоустройство территории».

| Поле | Описание |
|---|---|
| **Название вида работ** * | Наименование |
| **Код** | Внутренний код |
| **Описание** | Комментарий |

Вид работ используется при создании инспекции (вместе с категорией определяет
доступные шаблоны чек-листов) и при создании работы.

## 9.4. Единицы измерения

**Меню → Справочники → Единицы измерения**

![Единицы измерения](/user-guide/images/33-units-of-measure.png)

| Поле | Описание |
|---|---|
| **Наименование** * | «Квадратный метр» |
| **Обозначение** | «м²» |
| **Код ОКЕИ** | Код общероссийского классификатора |
| **Описание** | Комментарий |
| **Используется** | Счётчик записей, где единица применяется (только чтение) |

Единицы применяются в работах: объём по договору, выполнение, цена за единицу.

При импорте строка с известным названием **обновляется**, незнакомая **создаётся**.

## 9.7. Пользовательские поля

**Меню → Пользовательские поля**

![Пользовательские поля](/user-guide/images/36-external-fields.png)

Механизм расширения системы без доработки: добавляет собственные поля
к замечаниям, проектам и объектам.

### Создание поля

| Поле | Описание |
|---|---|
| **Название** * | Подпись, которую увидит пользователь |
| **Тип данных** * | См. таблицу ниже |
| **Тип** (сущность) | Замечания, Проекты или Объекты |
| **Группа** | Заголовок блока в форме: «Инженерия», «Документы», «Финансы» |
| **Обязательное** | Без заполнения запись не сохранится |
| **Категории замечания** | Показывать поле только для выбранных категорий; пусто — для всех |

### Типы данных и их настройки

| Тип | Настройки |
|---|---|
| **Текст** | Многострочное |
| **Целое число** | Мин / макс |
| **Десятичное** | Мин / макс, точность (0..10) |
| **Да/Нет** | Текст для TRUE, текст для FALSE |
| **Дата/время** | Режим: только дата, дата и время, только время; тип выбора: календарь или ролики; формат отображения |
| **JSON** | JSON schema (опционально) |
| **Справочник** | Источник: Пользователи или Контрагенты; множественный выбор |
| **Выбор из списка** | Значения списка, каждое с новой строки |

После сохранения поле появляется в формах и карточках в блоке
**«Пользовательские поля (N)»**, сгруппированное по заголовкам.

> Пользовательские поля можно использовать как **источник данных в шаблонах
> предписаний и отчётов по инспекциям** — при настройке параметра шаблона выберите
> источник «Пользовательское поле».

## 9.8. Права на справочники

Каждый справочник закрыт своим правом с действиями Просмотр / Создание /
Редактирование / Удаление:

| Справочник | Сущность права |
|---|---|
| Категории и типы замечаний | **Справочники замечаний**, **Категория**, **Тип замечания** |
| Контрагенты | **Контрагент** |
| Виды работ | **Вид работы инспекции** |
| Единицы измерения | **Единицы измерения** |
| Категории инспекций | **Категория инспекции** |
| Шаблоны чек-листов | **Шаблон чек-листа** |
| Пользовательские поля | **Пользовательские поля** |

Системные записи защищены от изменения — в меню появится пояснение
«Системная запись — изменение запрещено».
