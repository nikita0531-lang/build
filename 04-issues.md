## 4.1. Где живут замечания

| Экран | Что показывает |
|---|---|
| **Меню → Активные замечания** | Сквозной список по всем доступным проектам |
| **Карточка проекта → «Замечания»** | Только замечания этого проекта; здесь же создание |
| **Карточка объекта → «Замечания»** | Только по конкретному объекту |
| **Карточка инспекции → «Замечания»** | Заведённые в ходе проверки |
| **Карточка предписания → «Замечания»** | Включённые в документ |

![Замечания проекта](/user-guide/images/09-project-issues.png)

По умолчанию списки скрывают завершённые записи. Флажок **«Показать закрытые»**
добавляет замечания в статусах «Закрыто» и «Отклонено».

## 4.2. Создание замечания

**Карточка проекта → «Замечания» → «Добавить»**

![Форма создания замечания](/user-guide/images/27-issue-create-form.png)

### Проект и объект

| Поле | Описание |
|---|---|
| **Проект** * | Подставлен из контекста |
| **Объект** * | Узел дерева, к которому относится замечание |

### Классификация

| Поле | Описание |
|---|---|
| **Категория** * | Например «Лифтовое оборудование», «Каменная кладка» |
| **Тип** * | Конкретная формулировка внутри категории; список открывается после выбора категории |

Тип может быть обязательным — это включается настройкой проекта
**«Требовать тип замечания при создании»**.

### Срок и ответственный

| Поле | Описание |
|---|---|
| **Планируемая дата устранения** | Дата, к которой нужно устранить |
| **Контрагент** | Организация-исполнитель |
| **Ответственный** | Пользователь, отвечающий за устранение |

> **Срок считается сам.** Если у типа замечания задано ориентировочное время,
> система подставит дату устранения и покажет подсказку: «Срок устранения
> рассчитывается автоматически по типу замечания (⏱ 3 дн. 0 ч. 0 м.)».
> Дату можно поменять вручную.

Список ответственных ограничен пользователями, назначенными на этот проект.

### Описание и пользовательские поля

**Описание** — что именно не так. Обязательно заполнить хотя бы одно.

Кнопка **«Добавить описание»** добавляет ещё одно поле. Это приём массового ввода:
**каждое описание превращается в отдельное замечание** с одинаковыми проектом,
объектом, категорией, типом, сроком и ответственным. Под полями система показывает
«Будет создано замечаний: 5», а после сохранения — «Создано замечаний: 5».

Блок **«Пользовательские поля»** появляется, если администратор завёл дополнительные
поля для замечаний. Набор может зависеть от выбранной категории.

Нажмите **«Создать»**.

## 4.3. Карточка замечания

![Карточка замечания](/user-guide/images/10-issue-card.png)

**Шапка:** Проект, Объект, Категория, Тип, Описание, Создано, Статус, Приоритет,
Ответственный, Назначил, а также ссылки **Инспекция** и **Предписание**, если
замечание пришло из проверки или попало в документ. Проект, объект, инспекция и
предписание кликабельны.

Значок карандаша рядом с **«Ответственный»** открывает быстрое переназначение.
Меню **«⋮»** справа сверху — редактирование, смена статуса, приоритета,
ответственного, формирование предписания, удаление.

**Вкладки:**

| Вкладка | Содержимое |
|---|---|
| **План** | Положение замечания на плане объекта |
| **Вложения** | Фотографии и документы |
| **Чат** | Обсуждение с исполнителем |
| **Активность** | История изменений |

## 4.4. Жизненный цикл замечания

```
Новый ──────────► В работе ─────────► Выполнено ────────► На проверке ────► Закрыто
  │                  │  ▲                                      │
  │                  │  └───────── На доработку ◄───────────────┘
  │                  │                  │
  └──► Отклонено ◄───┘                  └──► Отклонено
              │
              └──► На проверке
```

| Из статуса | Куда можно | Кто может |
|---|---|---|
| **Новый** | В работе, Отклонено | Ответственный или обладатель права «Изменение статуса» |
| **В работе** | Выполнено, Отклонено | Ответственный или право |
| **Выполнено** | На проверке | **Только автор** замечания или право |
| **На проверке** | Закрыто, На доработку | **Только автор** или право |
| **На доработку** | В работе, Отклонено | Ответственный или право |
| **Отклонено** | На проверке | **Только автор** или право |
| **Закрыто** | — | конечный статус |

Логика простая: **исполнитель двигает работу вперёд, автор принимает результат**.
Ответственный отмечает «Выполнено», дальше мяч на стороне автора: он отправляет
на проверку и решает — закрыть или вернуть на доработку.

Смена статуса: **«⋮» → «Сменить статус»** и выбор из допустимых. Недопустимые
переходы в меню не показываются; при попытке обойти правила сервер ответит
«Переход в статус "X" из "Y" не допускается».

### Приоритеты

🔥 **Критичный** · **Высокий** · **Обычный** · **Низкий** · **Незначительный**

Меняется через **«⋮» → «Сменить приоритет»** (право «Изменение приоритета»).

## 4.5. Три представления списка

**Меню → Активные замечания** — вверху вкладки **Список · Канбан · Гант**.

### Список

![Список замечаний](/user-guide/images/11-active-issues.png)

Полноценная таблица: Статус, Приоритет, Проект, Объект, Контрагент, Категория, Тип,
Описание, Ответственный, Инспекция, Предписание, Планируемая дата устранения,
Создано (скрыта по умолчанию). Доступны сортировка, фильтры, группировка, поиск,
экспорт в XLSX.

### Канбан

![Канбан](/user-guide/images/12-issues-kanban.png)

Колонки — статусы, карточки — замечания: номер, название, проект, описание, приоритет,
ответственный.

Фильтры сверху: **«Выбрать проекты»**, **«Ответственные»**, **«Статусы замечаний»**.
Флажки **«Группировать по ответственному»** и **«Группировать по проекту»** разбивают
доску на дорожки.

### Гант

![Диаграмма Ганта](/user-guide/images/13-issues-gantt.png)

Замечания как задачи на временной шкале: Название, Начало, Окончание.
Масштаб — **День / Неделя / Месяц**, переключатель **«Связи»** показывает зависимости.
Удобно смотреть, что и когда просрочено.

## 4.6. Массовые операции

В списке отметьте флажками нужные строки — в панели появится **«Действия»**
и счётчик «Выбрано: 12».

| Действие | Что делает |
|---|---|
| **Очистить выбор** | Снять отметки |
| **Сменить статус** | Один статус для всех выбранных |
| **Сменить приоритет** | Один приоритет для всех |
| **Сменить ответственного** | Один исполнитель для всех |
| **Сформировать предписание** | Один документ по выбранным замечаниям |
| **Удалить** | Массовое удаление |

Операция выполняется **одной транзакцией**: если хотя бы одну запись обработать
нельзя, отменяется всё. Итог показывается в окне **«Результат операции»**:
«Операция выполнена успешно» либо «Операция отменена с ошибками» с указанием,
сколько замечаний обработано.

## 4.7. Формирование предписания из замечаний

Из строки: **«⋮» → «Сформировать предписание»**.
Из выбора: **«Действия» → «Сформировать предписание»**.

Система спросит подтверждение («Сформировать предписание по выбранным замечаниям (7)?»),
сформирует документ по активному DOCX-шаблону и сообщит «Предписание сформировано».
Подробности — [Предписания](/user-guide/05-prescriptions).

---

## 4.8. Импорт и экспорт

- **Импорт** — «Замечания_шаблон_импорт.xlsx».
- **XLSX** — выгрузка всего набора по текущим фильтрам, сортировке и поиску,
  а не только видимой страницы.

## 4.9. Права на замечания

| Право | Что открывает |
|---|---|
| **Просмотр** | Видеть замечания доступных проектов |
| **Просмотр всех** | Надпроектный просмотр — системное право для руководства и стройконтроля |
| **Создание** | Заводить новые |
| **Редактирование** | Менять поля |
| **Удаление** | Удалять |
| **Изменение статуса** | Двигать по статусам вне персональных правил |
| **Изменение приоритета** | Менять приоритет |
| **Изменение ответственного** | Переназначать исполнителя |
