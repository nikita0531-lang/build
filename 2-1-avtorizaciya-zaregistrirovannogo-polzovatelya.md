# 2.1. Авторизация зарегистрированного пользователя

Для доступа к серверу, перейдите по ссылке: [**https://platform.larix.ru/**](https://platform.larix.ru/).

В открывшемся окне введите логин и пароль, после чего нажмите кнопку **«Войти»**.

![Рисунок 2.1.1 – Окно авторизации](/larix-nexus/assets/img-001.png)

*Рисунок 2.1.1 – Окно авторизации*

В случае отсутствия учётных данных (логина и пароля) необходимо обратиться к Администратору Среды общих данных (далее - СОД).
