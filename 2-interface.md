## 2.1. Шапка

![Развёрнутое меню и шапка](/user-guide/images/03-sidebar-expanded.png)

Слева направо:

| Элемент | Назначение |
|---|---|
| **☰** | Свернуть / развернуть боковое меню |
| **Заголовок** | Название текущего экрана |
| **ПРОСТРАНСТВО** | Переключатель рабочего пространства |
| **RU / EN** | Язык интерфейса |
| **☀ / 🌙** | Светлая или тёмная тема |
| **Плотность** | Обычный или компактный режим — компактный вмещает больше строк на экран |
| **🔔** | Уведомления, с числом непрочитанных |

Тема, язык, плотность и выбранное пространство хранятся **в браузере на этом
устройстве** и на другой компьютер не переносятся.

### Рабочее пространство

![Переключатель пространства](/user-guide/images/53-workspace-switcher.png)

Пространство — изолированный контур данных. Переключение мгновенно меняет всё:
проекты, замечания, справочники, пользователей. Если запись «пропала» — первым делом
проверьте, в том ли вы пространстве.

Список пространств определяется назначениями, которые делает администратор
(**Менеджмент → Пользователи пространств**).

### Уведомления

![Панель уведомлений](/user-guide/images/52-notifications-panel.png)

Клик по колокольчику открывает панель:

- **«Только непрочитанные»** — фильтр списка;
- **«Прочитать все»** — снять счётчик со всех сразу;
- клик по уведомлению открывает связанную запись.

Какие события и по каким каналам вы получаете — настраивается в профиле,
см. [Уведомления и профиль](/user-guide/10-notifications).

## 2.2. Боковое меню

Меню собирается под ваши права: пункт, на который нет права просмотра, не отображается.

**Основные разделы**

- **Главная** — плитки проектов
- **Аналитика** — графики
- **Проекты** — реестр проектов
- **Активные замечания** — сквозной список замечаний по всем проектам
- **Предписания** — реестр предписаний *(лицензируемый модуль)*
- **Договоры**, **Работы** — учёт выполненных работ *(лицензируемый модуль)*
- **Инспекции** — реестр инспекций *(лицензируемый модуль)*
- **Пользовательские поля** — дополнительные поля к замечаниям, проектам и объектам

**Группы**

| Группа | Содержимое |
|---|---|
| **Справочники** | Справочники замечаний, Контрагенты, Виды работ, Единицы измерения, Категории инспекций, Шаблоны чек-листов |
| **Администрирование** | Пользователи, Роли |
| **Менеджмент** | Назначения, Роли и категории, Пространства, Пользователи пространств |

![Группа «Справочники»](/user-guide/images/49-menu-dictionaries.png)

![Группа «Администрирование»](/user-guide/images/50-menu-administration.png)

![Группа «Менеджмент»](/user-guide/images/51-menu-management.png)

**Нижний блок:** Настройки системы, Настройки шаблонов, Профиль, Выход.

## 2.3. Реестр: как читать и как им управлять

Большинство разделов — таблица-реестр с одинаковой механикой.

![Реестр замечаний](/user-guide/images/11-active-issues.png)

### Панель инструментов

| Кнопка | Действие |
|---|---|
| **Обновить** | Перечитать данные с сервера |
| **XLSX** | Выгрузить в Excel. Выгружается **весь набор по текущим фильтрам**, а не только видимая страница |
| **Импорт** | Загрузить записи из Excel |
| **Добавить** | Создать новую запись |
| **Поиск** | Строка поиска по содержимому таблицы |
| **▥** (справа) | Настроить колонки: показать, скрыть, изменить порядок |

### Работа с колонками

- **Сортировка** — клик по заголовку; повторный клик меняет направление.
- **Фильтр колонки** — значок воронки в заголовке.
- **Меню колонки** — «⋮» в заголовке: закрепление, скрытие, сортировка.
- **Ширина** — потяните границу заголовка.
- **Группировка** — перетащите заголовок в полосу
  «Перетащите сюда заголовок колонки для группировки».

Раскладка таблицы запоминается в браузере. Сбросить всё к виду по умолчанию:
**Профиль → «Сбросить настройки таблиц»**.

### Постраничный вывод

Слева внизу — размер страницы, справа — «Показано 1–20 из 20».

### Действия над строкой

В начале строки:

- **«глаз»** — открыть карточку на просмотр;
- **«⋮»** — контекстное меню.

Состав меню зависит от сущности и ваших прав; типовой набор:

| Пункт | Действие |
|---|---|
| **Просмотр** | Открыть карточку |
| **Редактировать** | Открыть форму изменения |
| **Сменить статус** | Подменю с допустимыми переходами |
| **Сменить приоритет** | Только для замечаний |
| **Сменить ответственного** | Только для замечаний |
| **Удалить** | Удаление с подтверждением |

Недоступный пункт остаётся видимым, но погашен, и при наведении объясняет причину:
**«Недостаточно прав»**, **«Системная запись — изменение запрещено»** или
**«Недостаточно прав для смены статуса этой записи»**.

> **Почему в подменю статусов не все статусы.** Показываются только переходы,
> разрешённые из текущего статуса. Полные схемы — в [справочнике](/user-guide/15-reference).

## 2.4. Формы создания и редактирования

Форма открывается поверх реестра и разбита на смысловые секции.

![Форма создания замечания](/user-guide/images/27-issue-create-form.png)

- Обязательные поля помечены **красной звёздочкой**.
- Сообщение об ошибке появляется под полем сразу после потери фокуса.
- **«Отмена»** закрывает форму без сохранения, **«Создать» / «Сохранить»** — сохраняет.
- Часть полей заполняется автоматически по контексту: например, при создании
  замечания из карточки проекта поле «Проект» уже подставлено.
- Выпадающие списки с большим количеством значений поддерживают набор для поиска.
- Зависимые списки блокируются, пока не выбрано ведущее значение: «Тип» станет
  доступен после выбора «Категории», «Объект» — после выбора «Проекта».

## 2.5. Импорт из Excel

Кнопка **«Импорт»** есть у большинства справочников и реестров.

1. Нажмите **«Импорт» → «Скачать шаблон импорта»**.
2. Заполните файл, не меняя строку заголовков.
3. Перетащите файл в окно импорта или нажмите **«Выбрать файл»**.
4. Дождитесь окончания и прочитайте отчёт **«Результат импорта»**:
   сколько строк загружено и построчный список ошибок.

Правила отличаются по разделам:

- **Справочники** — как правило, знакомая запись обновляется, незнакомая создаётся.
- **Работы и договоры** — записи **всегда создаются новые**: повторная загрузка того
  же файла добавит дубликаты.

Формат выгрузки совпадает с форматом импорта, поэтому реестр можно выгрузить,
поправить в Excel и залить обратно.

## 2.6. Вложения, чат и активность

Эти три вкладки есть в карточках замечания, инспекции, объекта, работы.

**Вложения** — файлы записи. Перетащите файлы в область или нажмите **«Прикрепить»**.
Для каждого файла видны автор, дата, тип, размер и **источник**: ручная загрузка,
чат, примечание или пункт чек-листа. Изображения открываются в просмотрщике.

**Чат** — обсуждение по записи. Файлы можно перетащить прямо в чат: сначала
загрузятся файлы, потом отправится сообщение. Вложения из чата попадают
во «Вложения» с источником «Чат».

**Активность** — история изменений: кто, когда и что поменял, в формате
«Изменено «Статус»: с «В работе» на «Выполнено»». Записи добавляются автоматически.

## 2.7. Личные настройки интерфейса

**Профиль → «Настройки интерфейса»**:

- **«Сбросить настройки таблиц»** — размеры страниц, фильтры, сортировки, порядок и
  ширины колонок во всех реестрах;
- **«Сбросить все локальные настройки»** — дополнительно тема, язык и выбранное
  пространство.

Данные системы и вход при сбросе не затрагиваются, страница перезагрузится.
