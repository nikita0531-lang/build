## 6.1. Подготовка: шаблон чек-листа

Инспекцию нельзя создать без шаблона чек-листа — сначала заведите его.

**Меню → Справочники → Шаблоны чек-листов → «Добавить»**

![Форма шаблона чек-листа](/user-guide/images/39-checklist-template-form.png)

**Шапка шаблона**

| Поле | Описание |
|---|---|
| **Название шаблона** * | Например «Приёмка лифтового оборудования» |
| **Категория** * | Категория инспекции |
| **Вид работ** * | Вид работ, к которому применяется |
| **Проект** | Ограничить шаблон одним проектом; пусто — общий |
| **Активен** | Неактивные шаблоны не предлагаются при создании инспекции |
| **Описание** | Комментарий |

**Структура чек-листа** — блоки, внутри блоков пункты.

- **«Добавить блок»** — раздел проверки, например «Испытания», «Безопасность»,
  «Качество». У блока есть название.
- **«Добавить пункт»** — конкретная проверка внутри блока.

**Поля пункта**

| Поле | Описание |
|---|---|
| **Пункт чек-листа** * | Формулировка проверки |
| **Тип ответа** | «Текст», «Да/Нет» или «Выбор из списка» |
| **Значения списка** | Для типа «Выбор из списка» — по одному значению в строке |
| **Обязательный** | Пункт нельзя оставить без ответа |
| **Допуск** | Подсказка инспектору: нормы, пределы, условия приёмки. Например «Не более 10 мм» |

Тип ответа определяет, что инспектор увидит на объекте: текстовое поле, переключатель
«Да/Нет» или выпадающий список.

Шаблон нельзя сохранить без хотя бы одного блока и хотя бы одного пункта в нём.

> Шаблоны копируются кнопкой в контекстном меню, выгружаются и загружаются
> через Excel — удобно переносить типовой набор проверок между проектами.

**Важно:** при создании инспекции чек-лист **копируется в неё целиком**. Дальнейшая
правка шаблона на уже созданные инспекции не влияет — исторические проверки
остаются такими, какими проводились.

## 6.2. Реестр инспекций

**Меню → Инспекции**

![Реестр инспекций](/user-guide/images/16-inspections.png)

Колонки: **Проект, Объект, Категория, Вид работ, Подрядчик, Инспектор, Ответственный,
Статус, Результат, Замечания, Работы, План. начало, Время начала, План. окончание,
Время окончания**.

Стрелка «›» в начале строки раскрывает вложенный список замечаний инспекции.

Действия по строке («⋮»): Просмотр, Редактировать, Сменить статус,
**«Скачать результат»**, Удалить.

> «Скачать результат» работает только для завершённых инспекций; иначе появится
> «Доступно только для завершённых инспекций».

## 6.3. Создание инспекции

**«Добавить»**

![Форма создания инспекции](/user-guide/images/28-inspection-create-form.png)

### Проект и объект

| Поле | Описание |
|---|---|
| **Проект** * | Проект проверки |
| **Объект** * | Конкретный объект дерева |

### Что проверяем

| Поле | Описание |
|---|---|
| **Категория** * | Тип проверки: «Операционный контроль», «Приёмка материалов», «Испытания инженерных систем», «Инспекция безопасности (HSE)», «Финальная приёмка этапа» |
| **Вид работ** * | Например «Сантехнические работы», «Фасадные работы» |
| **Шаблон чек-листа** * | Список фильтруется по категории и виду работ |

### Ответственные

| Поле | Описание |
|---|---|
| **Ответственный подрядчик** * | Контрагент, чью работу проверяем |
| **Инспектор** * | Кто проводит проверку |
| **Ответственный** * | Ответственный со стороны исполнителя |

### Плановые сроки

**Плановое начало** * и **Время начала**, **Плановое окончание** * и **Время окончания**.

### Загрузка инспектора

Значок календаря рядом с полем **«Инспектор»** открывает панель **«Загрузка
инспектора»** — занятость выбранного человека по всем проектам.

- Клик по свободному времени назначает инспекцию на этот слот.
- Жёлтый блок — планируемая инспекция; его можно двигать и растягивать.
- Пересечение подсвечивается: «Выбранное время пересекается с другой инспекцией
  этого инспектора».
- Если инспектор не выбран — «Сначала выберите инспектора».

Так проверки не назначаются на одного человека в одно время.

Нажмите **«Сохранить»**.

## 6.4. Карточка инспекции и проведение проверки

![Карточка инспекции](/user-guide/images/17-inspection-card.png)

**Шапка:** Проект, Объект, Категория, Вид работ, Подрядчик, Инспектор,
Ответственный, Статус, Результат, количество замечаний, плановые сроки.

**Вкладки:** **Чек-лист · Замечания · Работы · Вложения · Чат · Активность**.

**Управление статусом** — кнопки **«В работу»**, **«Завершить»**, **«Отменить»**.

### Работа с чек-листом

Чек-лист показан блоками. У каждого пункта:

- пометка **«Обязательный пункт»**, если он обязателен;
- плашка **«ДОПУСК»** с нормой из шаблона;
- поле **«Ответ»** — текст, «Да/Нет» или выбор из списка;
- **«Вложения»** — прикрепить фото или файл прямо к пункту;
- **«Замечания»** — создать замечание по этому пункту.

Счётчики показывают «Вложения: 2» и «Замечания: 1», а также автора и дату ответа.

**Создание замечания из пункта.** Нажмите **«+ Замечания»** — откроется форма
создания замечания с уже подставленными проектом, объектом и ссылкой на пункт
чек-листа. Созданное замечание попадает во вкладку «Замечания» инспекции, а в самом
замечании появляется ссылка «Инспекция №6». Именно так проверка превращается
в поручения.

### Вкладка «Работы»

Здесь видны записи журнала выполнения, отданные на приёмку этой инспекцией.
Вердикт инспекции определит их судьбу — см. [Учёт работ](/en/07-works).

## 6.5. Жизненный цикл инспекции

```
Не начата ──────► В работе ──────► Завершена
     │                 │
     └──► Отменена ◄───┘
```

| Из статуса | Куда можно |
|---|---|
| **Не начата** | В работе, Отменена |
| **В работе** | Завершена, Отменена |
| **Завершена** | — конечный |
| **Отменена** | — конечный |

Менять статус может **назначенный инспектор** либо обладатель права
«Инспекции: смена статуса». Иначе система покажет: «Менять статус может назначенный
инспектор или пользователь с правом «Инспекции: смена статуса»».

### Завершение и результат

При переводе в «Завершена» система требует указать **Результат**:

| Результат | Смысл |
|---|---|
| **Пройдена** | Замечаний нет, объём принимается |
| **Пройдена с замечаниями** | Объём **принимается**, но зафиксированы замечания — они устраняются отдельно |
| **Не пройдена** | Объём отклоняется |

Без результата завершить нельзя: «Необходимо указать результат инспекции».

Вердикт автоматически применяется к привязанным записям журнала выполнения:
«Пройдена» и «Пройдена с замечаниями» переводят объём в «Принят», «Не пройдена» —
в «Отклонён». Статус самой работы после этого пересчитывается системой.

## 6.6. Отчёт по инспекции

Для завершённой инспекции: **«⋮» → «Скачать результат»** или кнопка
**«Сформировать отчёт»**.

Отчёт собирается по DOCX-шаблону из раздела
**Настройки шаблонов → вкладка «Инспекции»** — см. [Администрирование](/en/11-administration).

---

## 6.7. Права на инспекции

| Право | Что открывает |
|---|---|
| **Просмотр** | Видеть реестр и карточки |
| **Просмотр всех** | Надпроектный просмотр (системное) |
| **Создание** | Планировать инспекции |
| **Редактирование** | Менять реквизиты и отвечать на пункты |
| **Удаление** | Удалять |
| **Изменение статуса** | Двигать по статусам, не будучи назначенным инспектором |

Отдельными правами закрыты справочники модуля: **Категория инспекции**,
**Вид работы инспекции**, **Шаблон чек-листа**.
