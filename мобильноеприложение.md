## 12.1. Вход и первый запуск

1. Введите **логин** и **пароль** — те же, что в веб-версии.
2. Если пароль выдан администратором, приложение сразу откроет экран смены пароля.
3. После входа выберите **пространство** (если доступно несколько).

Вход в приложение автоматически подключает канал **«Мобильные push»**: в веб-профиле
появится карточка с числом подключённых устройств.

---

## 12.2. Разделы

Нижняя навигация:

| Раздел | Что делает |
|---|---|
| **Замечания** | Список, карточка, создание |
| **Инспекции** | Список, карточка с чек-листом, создание *(модуль)* |
| **Работы** | Список, карточка, внесение выполнения *(модуль)* |
| **Настройки** | Аккаунт, внешний вид, офлайн-режим |

Разделы лицензируемых модулей закрыты заглушкой, если модуль не подключён.

## 12.3. Замечания

### Список

- **Поиск** по описанию, проекту, объекту, типу.
- **Фильтры**: проекты, статусы, приоритеты.
- **Сортировка**: «Сначала новые», «Сначала старые», «Критичные выше»,
  «Низкий приоритет выше», «Плановая дата ближе».
- **«Показывать закрытые и отклоненные»** — включить завершённые.
- **Потяните для обновления** — обновление списка жестом.
- **«Показать еще»** — подгрузка следующей порции.

### Создание замечания

Кнопка создания открывает форму:

**Проект** → **Объект** (выбор по дереву) → **Категория** → **Тип** →
**Приоритет** → **Плановая дата** → **Контрагент** → **Ответственный** →
**Что нужно исправить** (описание) → **Дополнительные поля**.

Фотографии прикладываются прямо с камеры или из галереи.

### Карточка замечания

Просмотр реквизитов, смена статуса, чат, вложения, ссылки на инспекцию и
предписание, план объекта с положением замечания.

## 12.4. Инспекции

- **Список** с фильтрами по проекту, статусу, категории.
- **Создание инспекции**: проект, объект, категория, вид работ, шаблон чек-листа,
  контрагент, инспектор, плановые сроки. Доступна панель **«Загрузка инспектора»**.
- **Проведение**: чек-лист блоками, у пункта — пометка «Обязательный пункт»,
  плашка **«Допуск»**, поле **«Ответ»**, вложения и создание замечания.
- **Завершение**: приложение не даст завершить, если не заполнены обязательные
  пункты («Заполните обязательные пункты чек-листа») или не выбран результат
  («Необходимо указать результат инспекции»).

---

## 12.5. Работы

- **Список работ** с поиском по наименованию, фильтрами и сортировкой
  («По наименованию», «Срок ближе»). Переключатель **«Показывать подработы
  отдельными строками»**.
- **Карточка работы**: объёмы, **«Принято»**, разделы работы, журнал.
- **Внесение выполнения**: **дата выполнения**, **объём**,
  **«Что именно выполнено»**, **«Этаж, оси, помещение»**, вложения.
  Проверки те же, что в вебе: «Укажите дату выполнения», «Укажите объём».

## 12.6. Офлайн-режим

Ключевая возможность для стройки без связи.

### Подготовка

**Настройки → «Перейти в оффлайн»**

> Скачиваем данные, чтобы приложение работало без сети.

- Выберите, **какие пространства скачать** — нужно минимум одно.
  Данные каждого пространства хранятся отдельно.
- Скачиваются справочники, шаблоны чек-листов, инспекции и карточки:
  «Справочники, инспекции и карточки сохранены на устройстве».
- Для входа в офлайн **нужен интернет**: «Для входа в оффлайн нужен интернет».

### Работа без сети

- Индикатор режима: **«В сети» / «Нет сети» / «Онлайн»**.
- Просмотр сохранённых данных: «Показаны сохранённые данные. Сервер недоступен»,
  «Показана сохраненная карточка. Сервер недоступен».
- Создание и вложения сохраняются локально: «Данные сохранены локально. Новые
  замечания попадут в очередь».
- Если запись не была скачана — «Замечание не найдено в оффлайн-кэше»,
  «Работа не сохранена для оффлайна».

### Синхронизация

При появлении связи: **«Синхронизировать»**.

- **«Показать очередь»** — что ещё не отправлено, со статусами «Ожидает»,
  «Синхронизация...», ошибки.
- **«Повторить ошибки»** — повторная отправка неудачных элементов.
- Итог: «Синхронизация завершена».

> **Ограничение:** созданная офлайн запись до синхронизации не видна в общем
> списке на сервере — она живёт в локальной очереди. Синхронизируйтесь при первой
> возможности, чтобы коллеги увидели вашу работу.

### Выход из офлайна

**«Выйти из оффлайна»** — «Выйти из оффлайн-режима и очистить локальный кэш».

> Локальный кэш будет очищен. Несинхронизированные данные тоже будут удалены.

**Сначала синхронизируйтесь**, потом выходите из офлайна.

## 12.7. Настройки приложения

| Блок | Содержимое |
|---|---|
| **Аккаунт** | Текущий пользователь, **«Выйти»** — завершить сессию |
| **Пространство** | Текущее пространство и переключение |
| **Внешний вид** | Тема: «Светлая», «Темная», «Автоматически следовать настройкам устройства» |
| **Локальные данные** | Размер локальной базы, **«Удалить локальные данные»** — кэш, справочники и очередь синхронизации |
| **Режим работы** | Переход в офлайн и обратно, очередь синхронизации |

> **«Удалить локальные данные»** необратимо: «Будут удалены кэш, справочники и
> очередь синхронизации». Несинхронизированные записи пропадут.

## 12.8. Уведомления на телефон

Push-канал подключается автоматически после входа. Какие события приходят —
настраивается в веб-профиле, колонка **«Пуш в мобильном приложении»**
(см. [Уведомления](/user-guide/10-notifications)).

Отключить конкретное устройство можно в профиле: карточка «Мобильные push»
показывает список подключённых устройств.
