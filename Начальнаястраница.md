## Что система умеет

**Замечания.** Фиксация несоответствия с описанием, категорией, типом, приоритетом,
ответственным, сроком устранения, фотографиями и точкой на плане. Ведение по статусной
модели от создания до закрытия, обсуждение в чате, полная история изменений.

**Инспекции.** Плановая проверка по шаблону чек-листа: инспектор отвечает на пункты,
прикладывает фото, из невыполненного пункта прямо на месте заводит замечание.
По завершении фиксируется результат и формируется отчёт в Word.

**Предписания.** Официальный документ подрядчику: выбираются замечания, система
подставляет их в DOCX-шаблон и создаёт предписание со своим статусом и сроками.

**Учёт выполненных работ.** Договоры, работы и подработы, журнал фактического
выполнения, приёмка объёмов через инспекции и выгрузка накопительного итога в КС-2.

**Организационный контур.** Пользователи, роли с точечными правами, назначение на
проекты, изолированные рабочие пространства, уведомления в Telegram / Max / Email /
мобильные push, аудит действий.

## Основные понятия

| Термин | Значение |
|---|---|
| **Рабочее пространство** | Изолированный контур данных. Проекты, замечания и справочники одного пространства не видны в другом. Переключается в шапке |
| **Проект** | Стройка или объект в целом: ЖК, больница, школа. Верхний уровень |
| **Объект** | Элемент дерева внутри проекта: корпус, секция, этаж, квартира, помещение. Объекты вложены друг в друга |
| **Замечание** | Зафиксированное несоответствие, требующее устранения. Имеет ответственного, срок и статус |
| **Инспекция** | Плановая проверка объекта по чек-листу с назначенным инспектором и подрядчиком |
| **Чек-лист** | Список проверяемых пунктов. Берётся из шаблона и копируется в инспекцию при создании |
| **Предписание** | Документ, выпущенный по одному или нескольким замечаниям |
| **Договор** | Договор подряда, в рамках которого ведутся работы |
| **Работа** | Позиция с плановым объёмом, ценой, сроками и ответственным |
| **Запись журнала выполнения** | Факт: сколько объёма выполнено в конкретный день |
| **Контрагент** | Юридическое лицо: подрядчик, заказчик, поставщик |
| **Право** | Разрешение на действие с типом записей, например «Замечание: создание» |
| **Роль** | Именованный набор прав, выдаваемый пользователю |

## Как пользоваться руководством

- Если вы **новый пользователь** — начните с разделов [1](/en/01-getting-started)
  и [2](/en/02-interface), затем откройте раздел своего участка работы.
- Если нужно **сделать конкретную вещь** — смотрите [Типовые сценарии](/en/13-scenarios).
- Если нужно **точное поведение статуса или права** — смотрите
  [справочник](/en/15-reference).

> **Про доступ.** Если пункта меню или кнопки нет — скорее всего, у вашей роли нет
> соответствующего права либо модуль не входит в лицензию. Это не сбой; обратитесь
> к администратору системы. Подробнее — [Администрирование](/en/11-administration).
