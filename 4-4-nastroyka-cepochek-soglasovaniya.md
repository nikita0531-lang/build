# 4.4. Настройка цепочек согласования

Перейдите на вкладку «Цепочки согласования» (1).

Список доступных цепочек согласования отображается в окне (3), при необходимости поиска или фильтрации можно использовать кнопки в поле (4).

![Рисунок 4.4.1. – Вкладка «Цепочки согласования»](/larix-nexus/assets/img-024.png)

*Рисунок 4.4.1. – Вкладка «Цепочки согласования»*

Для добавления новых цепочек согласования требуется нажать «Создать»(5).

Появится окно создания цепочки согласования:

![Рисунок 4.4.2. – Настройка этапа цепочки согласования](/larix-nexus/assets/img-025.png)

*Рисунок 4.4.2. – Настройка этапа цепочки согласования*

Необходимо ввести название этапа (1), указать срок согласования (2), выбрать пользователя из выпадающего списка (3), выбрать необходимые свойства (4).

Обязательность проверки – этап процесса согласования не завершится, пока пользователь не проставит статус документу.

Отмена процесса согласования – возможность у пользователя отменить процесс согласования.

Если требуется создать параллельный процесс согласования, нужно добавить несколько пользователей в один этап.

Для добавления пользователя нажать кнопку «добавить» (5), для удаления – «удалить» (6). Для добавления нового этапа необходимо нажать кнопку «Добавить этап» (7).

Есть возможность перемещения этапов. Для этого необходимо зажать кнопку (8) и перенести этап в нужное место цепочки. При необходимости можно удалить этап, нажав на кнопку «Удалить этап» (9).

После настройки всех этапов необходимо сохранить цепочку (10).

![Рисунок 4.4.3. – Действия с этапом цепочки согласования](/larix-nexus/assets/img-026.png)

*Рисунок 4.4.3. – Действия с этапом цепочки согласования*
