## 15.1. Статусы и переходы

### Проект

| Из | Куда |
|---|---|
| Новый | В работе |
| В работе | Закрыто |
| Закрыто | В работе |

### Объект проекта

| Из | Куда |
|---|---|
| Новый | В работе |
| В работе | Закрыто |
| Закрыто | В работе |

Закрытие объекта блокируется, если:

- не все дочерние объекты в том же статусе;
- не все замечания объекта закрыты;
- не все работы по объекту завершены (каждая принята или отменена).

### Замечание

| Из | Куда | Кто может |
|---|---|---|
| Новый | В работе, Отклонено | Ответственный |
| В работе | Выполнено, Отклонено | Ответственный |
| Выполнено | На проверке | Автор |
| На проверке | Закрыто, На доработку | Автор |
| На доработку | В работе, Отклонено | Ответственный |
| Отклонено | На проверке | Автор |
| Закрыто | — | — |

Право **«Замечание: изменение статуса»** снимает персональные ограничения.

### Предписание

| Из | Куда |
|---|---|
| Новый | В работе |
| В работе | Закрыто, Отклонено |
| Закрыто | — |
| Отклонено | — |

Персональное правило: ответственный. Право — «Предписание: изменение статуса».

### Инспекция

| Из | Куда |
|---|---|
| Не начата | В работе, Отменена |
| В работе | Завершена, Отменена |
| Завершена | — |
| Отменена | — |

Персональное правило: назначенный инспектор. Право — «Инспекция: изменение статуса».
При переводе в «Завершена» обязателен **результат**.

**Результаты инспекции:** Пройдена · Пройдена с замечаниями · Не пройдена.
Первые два принимают привязанные объёмы, третий — отклоняет.

### Работа

| Из | Куда | Примечание |
|---|---|---|
| План | Приостановлена, Отменена | «В работе» ставится автоматически при первом факте |
| В работе | Приостановлена, Отменена | «Выполнена» ставится автоматически, когда факт добирает план |
| Приостановлена | В работе, Отменена | Возобновление — ответственный |
| Выполнена | Отменена | «Принята» ставится автоматически, когда все записи приняты |
| Принята | Отменена | |
| Отменена | — | Конечный |

Перевод в «Приостановлена» требует указания причины.

### Запись журнала выполнения

| Из | Куда |
|---|---|
| В работе | Готов к приёмке |
| Готов к приёмке | Принят, Отклонён |
| Принят | Подписано |
| Отклонён | В работе |
| Подписано | — |
| Отменён | — |

## 15.3. Права: сущности и действия

**Действия**

| Действие | Смысл |
|---|---|
| Просмотр | Базовое право; предпосылка для остальных |
| Просмотр всех | Системное: надпроектный просмотр |
| Создание / Редактирование / Удаление | Операции над записями |
| Изменение статуса | Переходы вне персональных правил |
| Изменение приоритета | Замечания |
| Изменение ответственного | Замечания |
| Активация/Деактивация | Пользователи |
| Блокировка/Разблокировка | Пользователи |
| Изменение пароля | Пользователи |
| Разметка на плане | Зоны на планах |
| Маркеры на плане | Метки на планах |
| Выгрузка КС-2 | Договоры |

## 15.4. Лицензируемые модули

| Модуль | Что закрывает |
|---|---|
| **Инспекции** | Реестр и карточки инспекций, категории инспекций, шаблоны чек-листов, отчёты по инспекциям |
| **Предписания** | Реестр предписаний, формирование документов, шаблоны предписаний |
| **Учёт выполненных работ** | Договоры, работы, журнал выполнения, табель, аналитика работ, КС-2 |

Ядро системы — проекты, объекты, замечания, справочники, администрирование —
работает всегда.

Без модуля его экраны открываются **на чтение** с панелью «Модуль отключён».

## 15.5. Типичные сообщения и что они значат

| Сообщение | Причина | Решение |
|---|---|---|
| «Недостаточно прав» | У роли нет нужного права | Обратиться к администратору |
| «Системная запись — изменение запрещено» | Защищённая системная запись | Изменение невозможно |
| «Переход в статус "X" из "Y" не допускается» | Недопустимый переход | Смотреть схему статусов |
| «Запись уже в статусе "X"» | Повторная смена на тот же статус | Действие не требуется |
| «Менять статус может назначенный инспектор или пользователь с правом...» | Вы не инспектор этой проверки | Попросить инспектора или право |
| «Необходимо указать результат инспекции» | Завершение без результата | Выбрать результат |
| «Не все замечания в статусе "Закрыто"» | Закрытие объекта с открытыми замечаниями | Закрыть замечания |
| «Не все работы по объекту завершены» | Есть незавершённые работы | Принять или отменить работы |
| «Объект закрыт: работы и записи о выполнении в нём больше не меняются» | Объект закрыт | Вернуть объект в работу |
| «Выполнение вносится, пока работа в плане, в работе или выполнена» | Работа приостановлена, принята или отменена | Сменить статус работы |
| «У комплексной работы выполнение вносится в подработы» | Попытка внести факт в родителя | Вносить в подработу |
| «Без причины статус не сменить» | Приостановка без причины | Указать причину |
| «Работа выходит за рамки сроков договора» | Даты вне договора | Заполнить обоснование |
| «Значение поля "X" не уникально» | Дубликат | Изменить значение |
| «Нельзя управлять правом, которого нет у вас самих» | Попытка выдать право выше своего | Запросить право себе |
| «Модуль не входит в вашу лицензию» | Модуль не подключён | Обратиться к поставщику |
| «Слишком много запросов. Повторите позже» | Превышен лимит частоты | Подождать |

## 15.6. Быстрая диагностика «у меня ничего не видно»

Проверяйте по порядку:

1. **Пространство** — то ли выбрано в шапке?
2. **Назначение на проект** — Менеджмент → Назначения.
3. **Права роли** — Администрирование → Роли → вкладка «Права».
4. **Фильтры реестра** — не остался ли фильтр с прошлого раза;
   сбросьте через Профиль → «Сбросить настройки таблиц».
5. **«Показать закрытые»** — завершённые записи скрыты по умолчанию.
6. **Лицензия модуля** — Настройки системы → Лицензия.
7. **Учётная запись** — активна, не заблокирована.
