# 5.1. Общая информация

Проект – элемент системы, представляющий совокупность данных, документов, информационных моделей и процессов, связанных с реализуемым проектом, объединённых в едином пространстве для совместной работы всех участников.

Данный раздел имеет следующий набор функций:

- Работа с папками
- Загрузка документов
- Просмотр файлов формата.pdf,.xlsx,.docx,.imc,.ifc
- Настройка доступных действий в рамках ролевой модели.
- Набор действий с папкой и вложениями.
