## 8.1. Вкладка «Замечания»

![Аналитика по замечаниям](/user-guide/images/26-statistic.png)

### Фильтры

| Фильтр | Что делает |
|---|---|
| **Выбрать проекты** | Ограничить выборку проектами (можно несколько) |
| **Выбрать контрагентов** | Ограничить контрагентами |
| **С даты** / **По дату** | Период |
| **Обновить** | Пересчитать графики |

Справа — переключатель раскладки: список графиков в одну колонку или сетка.

### Графики

| График | Что показывает |
|---|---|
| **Замечания по статусам** | Круговая диаграмма: сколько замечаний в каждом статусе. Быстрый ответ на «сколько ещё не закрыто» |
| **Объекты по проектам и статусам** | Столбцы по проектам с разбивкой объектов по статусам |
| **Замечания по типам** | Какие нарушения повторяются чаще всего — основа для системных выводов |
| **Динамика замечаний по времени** | Созданные и закрытые по датам. Если «Создано» стабильно выше «Закрыто» — очередь растёт |
| **Замечания по проектам и статусам** | Столбцы по проектам с разбивкой по статусам: где скопилось |
| **Замечания по контрагентам** | Объём замечаний по подрядчикам |
| **Замечания по контрагентам и статусам** | То же с разбивкой по статусам: кто закрывает, а кто копит |

Легенда под графиком включает и выключает отдельные ряды.

## 8.2. Вкладка «Работы»

Аналитика модуля «Учёт выполненных работ».

| Элемент | Что показывает |
|---|---|
| **Договор**, **Проект** | Фильтры |
| **План** | Плановый объём |
| **Факт** | Выполненный объём |
| **Выполнение** | Процент выполнения |
| **Прогноз завершения** | Ожидаемая дата по текущему темпу; «Недостаточно данных», если статистики мало |
| **Накопительный итог (S-кривая)** | План против факта нарастающим итогом — видно опережение и отставание |
| **Освоение по видам работ** | Разрез по видам работ |

Если данных нет: «Данных для аналитики пока нет».

## 8.3. Дашборды внутри карточек

Помимо общей аналитики, срезы есть на месте:

- **Карточка проекта → «Обзор проекта»** — плитки по статусам, график замечаний,
  последние замечания.
- **Карточка объекта** — плитки Всего / Новых / В работе / Закрыто.
- **Карточка проекта → «Шахматка»** — карта замечаний по дереву объектов
  (см. [Проекты и объекты](/user-guide/03-projects)).
- **Карточка работы** — полоса выполнения и объёмы План / Выполнено / Принято / Остаток.

## 8.4. Выгрузка данных для собственных отчётов

Любой реестр выгружается в Excel кнопкой **XLSX** — **весь набор по текущим фильтрам**.
Это рабочий способ построить произвольный отчёт: отфильтруйте реестр,
выгрузите и сведите в Excel.
